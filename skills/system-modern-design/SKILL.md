# System Modern Design

Use this skill when styling, polishing, or redesigning the Campus Snack Bar POS interface.

## Design Goal

Create a clean, desktop-friendly point-of-sale screen that looks current but stays easy to finish, test, and explain within the IT415 practical exam. A plain working interface is better than an elaborate incomplete one.

## Scenario Context

The active scenario is Campus Snack Bar POS. The product list should visibly support these items and prices:

- Classic Burger - PHP 55.00
- Cheeseburger - PHP 65.00
- Ham Sandwich - PHP 40.00
- French Fries (Regular) - PHP 45.00
- Nachos - PHP 50.00
- Soda (Can) - PHP 25.00

## Visual Direction

Use a modern design only where it improves clarity:

- Keep the first screen focused on ordering, not a marketing landing page.
- Use a clear product area, cart/order summary area, payment area, and receipt area.
- Prefer restrained colors with strong contrast for text, prices, totals, errors, and success states.
- Use consistent spacing, aligned controls, readable labels, and predictable button placement.
- Make primary actions visually obvious: add item, confirm payment, and new transaction.
- Make destructive actions such as remove item visually distinct but not distracting.

## Constraints

Do not spend exam effort on advanced visual features that are not required:

- No animation-heavy experience.
- No product image requirement unless the user already has assets.
- No authentication screen.
- No dashboard, inventory panel, sales reports, or deployment banner.
- No design element that hides required transaction information.

## Quality Checks

Before finalizing design work, confirm:

- Product names and prices are readable at normal desktop/laptop size.
- Cart rows show item name, quantity, subtotal, and controls clearly.
- Total amount, amount paid, change, and transaction reference are easy to find.
- Error and success messages are readable and visually different.
- The layout still works when several products are in the cart.
